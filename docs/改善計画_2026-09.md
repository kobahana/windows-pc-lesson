# PCレッスン 改善計画・仕様書（2026年9月）

半年間の運用をふまえた大型アップデートの仕様。

## 1. 背景と目標

- 対象：N2〜N3レベルの留学生。ほとんどが**パソコンをほぼ触ったことがない**。
- 最終目標：就職後、仕事でパソコンを使うことに**苦手意識がない**状態まで育てる。
  1. Googleドキュメントで**ビジネス文書**、Googleスプレッドシートで**請求書**が作れる
  2. **どんなアプリでもなんとなく使い方がわかる**リテラシー
  3. 基本的なキーボード操作・ショートカットの習得

### 半年運用で見えた課題

| 課題 | 原因 |
|---|---|
| コピペ・戻る・リロードが定着しない | 1回やって終わり／復習の場がない／模擬画面だけで本物で練習していない |
| 半角/全角の切り替えができない | L1ミッション2は画面の「あ/A」ボタンでもクリアでき、本物のキーを押さずに済んでしまう |
| 学籍番号を全角で入れる | ログイン画面が入力をそのまま保存 → 全角/半角で**記録が別人扱い**になる恐れ |
| クリップボードが理解できない | 目に見えない仕組みを説明していない |

## 2. 設計方針

- **Fキー（F1〜F12）は使わない**。カタカナはスペース変換、リロードは Ctrl+R かボタン。
- **ショートカットは「どのアプリでも同じもの」に絞る**（Ctrl+C/V/X/Z/Y/A/S/F/P、戻る、リロード など）。
- **書式（揃え・太字・箇条書き・罫線・結合…）はツールバーのボタンで**教える。
  アイコンを見て何ができるか推測できる力 ＝ どんなアプリでも使える力。
- **アプリ共通の5つのルール**を全レッスンの合言葉にする
  1. 先に選んでから、操作する
  2. アイコンは形から予想して、マウスを乗せて名前を確かめる
  3. 迷ったら右クリック
  4. メニューの場所はだいたい決まっている（ファイル・編集・表示、⋮、☰、⚙）
  5. 失敗したら Ctrl+Z（こわがらずに試す）
- **本物の操作で判定**できるものは本物で（ブラウザの戻る/リロード、実際のキー入力、実際の貼り付け）。
- 判定できない本物のアプリ（Googleドキュメント等）は「アプリ内で練習 → 本物で仕上げ＋チェックリスト」の2段階。
- 間違いは**種類ごとに具体的な声かけ**（全角になっている／＝が全角／×を探している 等）。
- UI文言は従来どおり「短い日本語＋ふりがな＋短い英語」。

## 3. 追加・変更する機能

### 3-0. ログイン画面の入力チェック（記録分裂の防止）
- 学籍番号：全角英数を検出したら「全角になってるよ。半角/全角キーを押してね」と表示し、ログインさせない（練習の機会にする）。形式はまとめテストと同じ `2024k001`（数字4＋英字1＋数字3）。大文字は小文字に正規化。
- 名前（任意）：入れる場合は全角カタカナ。ひらがな・半角カタカナ・ローマ字それぞれに声かけ。
- 入力チェックは `lib/input-check.ts` に共通化し、まとめテストと共用。

### 3-1. レッスン6「毎日つかう基本ワザ」（lessonId 7）
| ミッション | 内容 | 判定方法 |
|---|---|---|
| 1 入力モード | 学籍番号（半角）→名前（カタカナ）→メール（半角）→電話（半角）を交互に入力。カタカナはスペース変換 | 入力文字の種類を判定し、間違いの種類ごとに声かけ |
| 2 コピー＆ペースト | クリップボードを画面に「見える化」。コピー→貼り付け、上書きされる体験、切り取り、Ctrl+A、住所/URL/メールを写す | 実際の copy / cut / paste イベント |
| 3 ブラウザ | 本物の戻るボタン・Alt+←、リロードボタン・Ctrl+R、新しいタブ、Ctrl+F | popstate・navigation type・visibilitychange・keydown |
| 4 5つのルール | 選んでから操作／アイコンを予想／右クリック／メニュー／Ctrl+Z をミニ課題で体験 | 画面内の操作 |

### 3-2. レッスン7「ビジネス文書をつくろう」（lessonId 8）
| ミッション | 内容 |
|---|---|
| 1 アイコンを読もう | Googleドキュメント風ツールバーのアイコンを見て、何をするボタンか予想→マウスを乗せて確かめる |
| 2 要点を箇条書きに | 文章から要点を拾う（クリックで選ぶ→短い形と線で結ぶ→自分で入力）。「日時：」のラベル、名詞止めの型 |
| 3 文書を整えよう | 練習用エディタで「無題のドキュメント」の名前変更、宛名左・日付右・件名中央太字・文字サイズ・「記」の箇条書き・「以上」右揃え。**すべてボタン操作**。自動判定 |
| 4 本物で仕上げ | 本物のGoogleドキュメントで同じ文書を作成 → チェックリスト → PDFダウンロード・共有リンクの説明 |

### 3-3. レッスン8「請求書をつくろう」（lessonId 9）
| ミッション | 内容 |
|---|---|
| 1 四則計算 | 足し算・引き算・掛け算（*）・割り算（/）を**数で入れる**／**セルで入れる**の両方。全角＝、＝忘れ、×÷に声かけ |
| 2 セルで入れる理由 | 数の式とセルの式を並べ、単価を書き換えると片方だけ自動で変わる体験 |
| 3 請求書 | ファイル名、タイトル入力、セル結合、金額＝単価*数量、オートフィル、SUM、消費税、罫線、¥表示。**ボタン操作** |
| 4 本物で仕上げ | 本物のGoogleスプレッドシートで作成 → チェックリスト |

### 3-4. レッスン9「仕事で困らないパソコン術」（lessonId 10）
| ミッション | 内容 |
|---|---|
| 1 ファイルとフォルダ | 模擬エクスプローラー：ダウンロードフォルダ、フォルダ作成、名前の付け方（日付_内容_相手）、拡張子の見分け |
| 2 ビジネスメール | 模擬Gmail：宛先/CC/BCC、件名、添付、返信と全員に返信、送信前チェック |
| 3 セキュリティ | 怪しいメール・SMS・偽ログイン画面を見分ける、パスワード、画面ロック（Windows+L） |
| 4 困ったとき | スクリーンショット（Windows+Shift+S）を撮って**本当に貼り付ける**、質問のしかた、ウィンドウを並べる（Windows+←/→）、オンライン会議のボタン、検索と翻訳ツールの使い方 |

### 3-5. レッスン10「初めて見るアプリにチャレンジ」（lessonId 11）
- 見た目の違う架空アプリ（メモアプリ／予約アプリ／Excel風表計算）で、5つのルールを使って課題を解く。手順は教えない。

### 3-6. ショートカット・パスポート
- `lib/skills.ts` に習得項目（ショートカット・操作）を ★1〜★3 で定義。
- レッスン・ウォームアップで合格すると記録（生徒ごと、端末内＋スプレッドシート送信）。
- ホーム画面にパスポート（スタンプ帳）を表示。
- パスポートのカードを押すと、その操作を練習できる場所へ飛ぶ。ウォームアップに問題があればその1問（`/warmup?task=ID`）、なければレッスンのミッション（`/lessons/lessonN?mission=M`、`lib/skills.ts` の `lesson`）。スキルを足すときはどちらかを用意する。
- スタンプの色は黄色（amber）で統一（ホームのボタン・パスポート・スタンプGET・先生用の表）。赤（rose）はウォームアップの色。

### 3-7. ウォームアップ（/warmup）
- 授業のはじめ2〜3分。**まだ合格していない項目を優先して3問**出題（全部合格済みならランダム）。
- 本物のキー操作で判定（コピペ、切り取り、Ctrl+Z/Y、Ctrl+A、Ctrl+S、Tab、半角/カタカナ入力 など）。

### 3-8. タイピング計測（/typing）
- 1分間で何文字打てるか計測。記録をグラフで表示し、目安ライン（初級30／中級60／就職目標80 文字/分）を表示。

### 3-9. PC操作テスト（/skill-test）
- まとめテスト（漢字変換）はそのまま。**別に「PC操作テスト」**を追加（5分間・操作問題）。
- 表示は既存の「まとめテスト」スイッチで一緒に切り替わる（Apps Script の変更不要にするため）。

### 3-10. 先生用ページ
- クリア状況を L1〜L10 に拡張。
- ショートカット習得表（生徒×項目）を追加（この端末の記録）。

## 4. データ設計

- 既存：lessonId 1〜5 がレッスン、**6 がまとめテスト**（既存データ互換のため変更しない）。
- 新規：レッスン6〜10 は **lessonId 7〜11**（画面上の表示番号は 6〜10）、ウォームアップ 12、タイピング計測 13、PC操作テスト 14。
- `StudentRecord` に `skills?: Record<skillId, 合格日時ISO>` と `typing?: { at, cpm }[]` を追加（任意項目なので旧データはそのまま読める）。
- ActivityType に `skill_clear`（スキル合格）を追加。スプレッドシートには既存の列形式で送る（Apps Script 変更不要）。

### 判定できないもの・制約
- Windows+L（画面ロック）はブラウザで検知できないため、クイズで合格とする。
- Alt+Tab・画面を並べる・スクリーンショットは、学校のPCの設定によってはできないため「スキップ」ボタンあり（スタンプは付かない）。
- L1 ミッション2 の「あ/A」ボタンは従来のまま。本物の半角/全角キーの練習は L6 ミッション1 で行う。
- PC操作テストは、まとめテストと同じスイッチで表示される（Apps Script の変更なし）。受験済み判定は、まとめテストと同じく「学籍番号ごと・タブを閉じるまで」。
